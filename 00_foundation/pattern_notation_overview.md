# Pattern Notation Overview

Crochet patterns can be represented in several forms.

## Written Instructions

Example:

`Row 1: Ch 21. Dc in 4th ch from hook and each ch across. Turn.`

Written patterns are linear and instruction-based.

## Symbol Charts

Symbol charts map each stitch to a glyph. They are especially useful for lace, doilies, and complex motifs.

## Grid Charts

Filet, tapestry, mosaic, and pixel-style crochet often use square grids.

## Repeat Notation

Patterns often use brackets and stars:

- `*dc, ch 1, sk 1* repeat across`
- `[2 dc, ch 2, 2 dc] in corner`

## Generative Use

A RepoScripter agent can convert written patterns into graphs, charts, and prompts by recognizing stitch tokens, repeats, row turns, and round joins.
