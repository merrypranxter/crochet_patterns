# Core Definition

Crochet is a hook-built textile system made by pulling loops through loops. It can produce dense fabric, lace mesh, sculptural forms, motifs, relief textures, cables, shells, plush shapes, and mathematical surfaces.

The smallest useful unit is not a pixel. It is a loop event.

A crochet pattern is a sequence of loop events placed into target locations:

- a previous stitch
- a chain space
- a ring
- a post
- a back loop or front loop
- an edge
- a joined motif

## Visual DNA

Crochet surfaces usually show:

- visible loops and knots
- vertical stitch posts
- horizontal row ridges
- chain spaces and holes
- soft dimensional relief
- scalloped or stepped edges
- repeating units
- hand-tension variation
- yarn twist and fiber fuzz
