# Terminology And Abbreviations

## Common US Terms

- ch: chain
- sl st: slip stitch
- sc: single crochet
- hdc: half double crochet
- dc: double crochet
- tr: treble crochet
- st: stitch
- sp: space
- sk: skip
- inc: increase
- dec: decrease
- BLO: back loop only
- FLO: front loop only
- fpdc: front post double crochet
- bpdc: back post double crochet

## UK Term Warning

US and UK crochet terms use the same names for different stitch heights.

A US single crochet is roughly a UK double crochet. A US double crochet is roughly a UK treble crochet.

Every pattern file should state which terminology system it uses.

## Repo Default

This repo defaults to US terminology unless stated otherwise.
