# Crochet Vs Knitting Vs Weaving

Crochet, knitting, and weaving all use yarn or thread, but their construction logic is different.

## Crochet

Crochet uses one hook and usually one active loop. Stitches are built by pulling yarn through loops and anchoring into existing stitch locations.

Visual tells:

- knot-like stitch bodies
- chain edges
- thick vertical posts
- sculptural relief
- more freeform shaping
- easy radial motifs

## Knitting

Knitting uses needles and many live loops. Fabric forms as rows of interlocking loops.

Visual tells:

- V-shaped knit stitches
- purl bumps
- elastic drape
- uniform columns

## Weaving

Weaving interlaces warp and weft threads under/over each other.

Visual tells:

- grid interlacing
- warp/weft orthogonality
- thread crossings
- loom logic

## Anti-Drift Rule

Do not let crochet prompts become generic yarn texture. Crochet needs stitch bodies, chain spaces, hook-built loops, and pattern instructions.
