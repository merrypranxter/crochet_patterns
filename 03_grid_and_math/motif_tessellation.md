# Motif Tessellation

Motifs can tile as squares, hexagons, triangles, circles with joins, or irregular freeform scrumbles. Joins must be treated as pattern events, not decoration.

## Parameters To Track

- stitch count
- row or round index
- increase interval
- repeat width
- repeat height
- motif unit
- join points
- color index
- tension / gauge

## Prompt / Code Translation

Use this file as a bridge between real crochet logic and generative pattern systems. The goal is not always to produce a literal craft pattern. Sometimes the goal is a visual system that behaves like crochet.
