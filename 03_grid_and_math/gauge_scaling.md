# Gauge Scaling

Gauge converts stitch counts into physical dimensions. A pattern generator should track stitches per inch, rows per inch, yarn weight, hook size, and desired finished size.

## Parameters To Track

- stitch count
- row or round index
- increase interval
- repeat width
- repeat height
- motif unit
- join points
- color index
- tension / gauge

## Prompt / Code Translation

Use this file as a bridge between real crochet logic and generative pattern systems. The goal is not always to produce a literal craft pattern. Sometimes the goal is a visual system that behaves like crochet.
