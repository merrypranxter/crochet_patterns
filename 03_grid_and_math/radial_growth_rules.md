# Radial Growth Rules

Radial crochet needs controlled increases. Flat circles increase at predictable intervals; too many increases create ruffles, too few create bowls.

## Parameters To Track

- stitch count
- row or round index
- increase interval
- repeat width
- repeat height
- motif unit
- join points
- color index
- tension / gauge

## Prompt / Code Translation

Use this file as a bridge between real crochet logic and generative pattern systems. The goal is not always to produce a literal craft pattern. Sometimes the goal is a visual system that behaves like crochet.
