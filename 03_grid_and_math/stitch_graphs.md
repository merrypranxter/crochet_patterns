# Stitch Graphs

Crochet patterns can be represented as graphs where stitches are nodes, yarn paths are edges, and chain spaces are faces. This is useful for chart generation, validation, and procedural pattern growth.

## Parameters To Track

- stitch count
- row or round index
- increase interval
- repeat width
- repeat height
- motif unit
- join points
- color index
- tension / gauge

## Prompt / Code Translation

Use this file as a bridge between real crochet logic and generative pattern systems. The goal is not always to produce a literal craft pattern. Sometimes the goal is a visual system that behaves like crochet.
