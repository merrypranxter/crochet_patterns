# Symmetry And Repeats

Crochet motifs often use rotational symmetry, mirror symmetry, translation repeats, and corner repeats. These can map directly to tiling systems and shader repeats.

## Parameters To Track

- stitch count
- row or round index
- increase interval
- repeat width
- repeat height
- motif unit
- join points
- color index
- tension / gauge

## Prompt / Code Translation

Use this file as a bridge between real crochet logic and generative pattern systems. The goal is not always to produce a literal craft pattern. Sometimes the goal is a visual system that behaves like crochet.
