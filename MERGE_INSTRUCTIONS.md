# Merge Instructions

Unzip this archive into the root of the `crochet_patterns` repository.

Recommended order after merging:

1. Read `repo_structure/crochet_patterns_repo_instructions.md`.
2. Read `00_foundation/core_definition.md` and `00_foundation/crochet_as_loop_topology.md`.
3. Use `01_stitch_library/` as the stitch vocabulary backbone.
4. Use `02_pattern_families/` as the pattern-family reference.
5. Use `data/stitch_library.json` and `data/pattern_families.json` for programmatic pattern generation.
6. Use `code/p5/` and `code/glsl/` as starter visuals.
7. Use `agents/copilot_agent_prompt.md` to make Copilot expand the repo further.

Do not overwrite existing files blindly. This pack is additive.
