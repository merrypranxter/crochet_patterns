# Crochet Patterns Repo Instructions

This repository should function as a style bible, pattern grammar, prompt library, and code reference for crochet-based textile systems.

## Repository Goals

The repo should help an AI system understand crochet through multiple lenses:

- physical craft construction
- visual texture and stitch behavior
- mathematical grid / graph / topology behavior
- textile pattern families
- AI prompt generation
- shader and generative art translation
- app integration and parameter controls

## File Expectations

Markdown files should include:

- definition
- visual traits
- construction logic
- repeat logic
- use cases
- prompt vocabulary
- drift warnings

Data files should be valid JSON or CSV.

Code files should be standalone whenever possible and easy to modify.

## Voice

Keep it useful, specific, and visual. Avoid sterile craft-blog mush. Crochet is loops, knots, holes, tension, topology, color rhythm, and soft structure.
