# Shell Stitches

Multiple tall stitches worked into the same stitch or space to create fan shapes.

## Visual Traits

- fans
- scallops
- petal clusters

## Construction Logic

A stitch can be modeled by its insertion target, yarn-over count, draw-through sequence, height, and resulting top loop. For generative systems, these become parameters rather than literal craft steps.

## Useful For

- lace borders
- blankets
- decorative repeats

## Prompt Vocabulary

Use phrases like: `shell stitches`, hook-built loops, visible yarn path, stitch bodies, chain spaces, loop texture, tactile relief, handmade tension variation.

## Drift Warnings

Do not turn this into generic knitted texture. Crochet stitches have knots, posts, chain spaces, and hook-built loop paths.
