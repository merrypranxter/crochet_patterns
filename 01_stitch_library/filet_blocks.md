# Filet Blocks

Open and filled mesh blocks used to make images, letters, and lace diagrams.

## Visual Traits

- square windows
- filled blocks
- pixel-like lace

## Construction Logic

A stitch can be modeled by its insertion target, yarn-over count, draw-through sequence, height, and resulting top loop. For generative systems, these become parameters rather than literal craft steps.

## Useful For

- filet charts
- curtains
- monograms
- graphic lace

## Prompt Vocabulary

Use phrases like: `filet blocks`, hook-built loops, visible yarn path, stitch bodies, chain spaces, loop texture, tactile relief, handmade tension variation.

## Drift Warnings

Do not turn this into generic knitted texture. Crochet stitches have knots, posts, chain spaces, and hook-built loop paths.
