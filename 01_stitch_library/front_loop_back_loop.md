# Front Loop Back Loop

Loop-target variations that change ridge direction and fabric texture.

## Visual Traits

- surface ridges
- ribbing
- hinge folds

## Construction Logic

A stitch can be modeled by its insertion target, yarn-over count, draw-through sequence, height, and resulting top loop. For generative systems, these become parameters rather than literal craft steps.

## Useful For

- ribbed cuffs
- textural stripes
- fold lines

## Prompt Vocabulary

Use phrases like: `front loop back loop`, hook-built loops, visible yarn path, stitch bodies, chain spaces, loop texture, tactile relief, handmade tension variation.

## Drift Warnings

Do not turn this into generic knitted texture. Crochet stitches have knots, posts, chain spaces, and hook-built loop paths.
