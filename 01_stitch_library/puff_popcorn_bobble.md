# Puff Popcorn Bobble

Dimensional cluster stitches that create raised bumps and tactile texture.

## Visual Traits

- bubbles
- nubs
- soft relief

## Construction Logic

A stitch can be modeled by its insertion target, yarn-over count, draw-through sequence, height, and resulting top loop. For generative systems, these become parameters rather than literal craft steps.

## Useful For

- texture fields
- berries
- polka-dot fabric

## Prompt Vocabulary

Use phrases like: `puff popcorn bobble`, hook-built loops, visible yarn path, stitch bodies, chain spaces, loop texture, tactile relief, handmade tension variation.

## Drift Warnings

Do not turn this into generic knitted texture. Crochet stitches have knots, posts, chain spaces, and hook-built loop paths.
