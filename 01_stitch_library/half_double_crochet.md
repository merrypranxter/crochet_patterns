# Half Double Crochet

A medium-height stitch with a slightly ridged, flexible fabric.

## Visual Traits

- soft horizontal bar
- medium height
- subtle rib

## Construction Logic

A stitch can be modeled by its insertion target, yarn-over count, draw-through sequence, height, and resulting top loop. For generative systems, these become parameters rather than literal craft steps.

## Useful For

- blankets
- garments
- fast textured fields

## Prompt Vocabulary

Use phrases like: `half double crochet`, hook-built loops, visible yarn path, stitch bodies, chain spaces, loop texture, tactile relief, handmade tension variation.

## Drift Warnings

Do not turn this into generic knitted texture. Crochet stitches have knots, posts, chain spaces, and hook-built loop paths.
