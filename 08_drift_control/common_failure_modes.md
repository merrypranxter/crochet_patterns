# Common Failure Modes

## Generic Yarn Sludge

The model makes soft yarn fuzz but no readable stitch structure.

Repair: ask for visible individual stitch bodies, chain spaces, and hook-built loops.

## Knitting Drift

The model creates V-shaped knit stitches.

Repair: explicitly ban knitting and ask for crochet posts, chain spaces, and single/double crochet stitches.

## Printed Lace Drift

The model makes a flat printed lace pattern with no yarn relief.

Repair: add yarn thickness, shadows, loops, and stitch-local relief.

## Impossible Pattern Drift

The design looks pretty but could not exist as a crochet repeat.

Repair: add row/round/motif logic and repeat-unit constraints.
