# What This Style Is Not

Crochet pattern logic is not:

- knitting texture
- woven fabric grid
- generic yarn ball aesthetic
- printed lace
- flat wallpaper ornament
- macrame knots
- embroidery stitches
- random cozy craft vibes

Crochet needs visible hook-built loop structure. If the surface does not show stitch bodies, chain spaces, row/round logic, or motif construction, it has drifted.
