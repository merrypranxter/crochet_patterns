# Crochet Patterns Beef Pack 01

This pack expands `crochet_patterns` into a usable style / pattern / code repo for crochet as a visual, mathematical, textile, and generative system.

It is designed for:

- AI art prompt generation
- textile pattern generation
- crochet chart logic
- stitch vocabulary and symbol translation
- shader / p5.js / SVG experiments
- math-based fabric pattern systems
- Copilot / RepoScripter expansion
- drift prevention so the repo does not become vague yarn aesthetic soup

## Core Idea

Crochet is not only a craft category. It is a loop-based construction grammar.

A crochet surface is made from a small vocabulary of operations:

- pull loop through loop
- insert hook into target location
- yarn over
- draw through one or more loops
- stack height
- skip space
- repeat unit
- increase / decrease
- turn / spiral / join

From those simple moves you get lace, shells, cables, granny squares, plush forms, hyperbolic planes, doilies, mesh, tapestry colorwork, and deeply weird fiber math.

## How To Use This Pack

Unzip this pack into the root of `crochet_patterns`. It will add documentation, structured data, reusable prompts, and starter code templates.

The pack is intentionally modular: you can use only the docs, only the data, only the code templates, or all of it as a big crochet goblin machine.
