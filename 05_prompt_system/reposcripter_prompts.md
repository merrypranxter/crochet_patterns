# RepoScripter Prompts

## Simple Textile Pattern Prompt

```text
Use the attached GitHub repos as context. Create a clean textile pattern concept based on crochet pattern logic. Use visible hook-built loops, a clear repeat structure, and one recognizable crochet family such as granny square, shell lace, filet crochet, mosaic crochet, or ripple chevron. Keep it visually readable and not overly weird. Output a concise art/code prompt.
```

## Shader Prompt

```text
Use the attached GitHub repos as context. Generate a shader concept that simulates a crochet textile surface. The shader should use repeated loop-shaped stitch glyphs, yarn twist noise, soft stitch-local shadows, and a controllable pattern family such as granny square grid, ripple chevron rows, filet crochet mesh, or hyperbolic ruffle growth. Include useful uniforms such as stitchScale, yarnFuzz, colorCount, reliefDepth, repeatSize, and time.
```

## Math Fabric Prompt

```text
Use the attached GitHub repos as context. Create a math-based crochet textile design where stitch placement follows a mathematical rule: radial growth, cellular automata, tessellation, wave interference, graph traversal, or hyperbolic expansion. Preserve crochet-specific visual details: loops, chain spaces, stitch posts, motif joins, yarn texture, and handmade tension variation.
```
