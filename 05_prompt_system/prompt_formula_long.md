# Prompt Formula Long

```text
Create a textile design based on [PATTERN FAMILY] crochet. The surface should show [STITCH TYPES] constructed as visible hook-built loops with yarn twist, fiber fuzz, and small stitch-local shadows. Use [ROW/ROUND/MOTIF LOGIC] with [REPEAT STRUCTURE]. Color behavior should follow [COLOR SYSTEM]. Preserve crochet-specific construction: chain spaces, stitch posts, top loops, increases/decreases, motif joins, and handmade tension variation. Avoid knitting, weaving, printed lace, and generic yarn texture.
```

## Fill-In Variables

- PATTERN FAMILY: granny square, ripple chevron, filet, tapestry, mosaic, shell lace, doily mandala, hyperbolic crochet
- STITCH TYPES: chain, single crochet, double crochet, shells, bobbles, post stitches
- ROW/ROUND/MOTIF LOGIC: row repeat, joined rounds, spiral rounds, square motif joins, radial increases
- REPEAT STRUCTURE: 8-stitch repeat, corner cluster repeat, checker grid, radial 12-spoke symmetry
- COLOR SYSTEM: two-color contrast, variegated yarn, color rounds, gradient yarn, acidic pop palette
