# Prompt Formula Short

Use this when you want a quick textile/image prompt.

```text
[SUBJECT OR SURFACE], crochet pattern logic, [PATTERN FAMILY], visible hook-built loops, [STITCH TYPE], [COLOR LOGIC], yarn texture, handmade tension variation, chart-readable repeat structure
```

## Examples

```text
acidic rainbow textile surface, crochet pattern logic, granny square motif grid, visible hook-built loops, double crochet clusters, hot pink teal yellow purple color rounds, yarn texture, handmade tension variation
```

```text
black and cream geometric fabric, mosaic crochet logic, stepped overlay bars, dense single crochet ground, high contrast colorwork, chart-readable repeat structure
```
