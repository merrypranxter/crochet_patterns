# Shader Prompt Templates

## Loop Field Shader

```text
Create a GLSL shader that renders a crochet-inspired stitch field. Use repeated loop-shaped SDF glyphs arranged on a grid, with yarn twist noise, soft relief shadows, and slight per-stitch tension jitter. Parameters: stitchScale, loopWidth, yarnFuzz, reliefDepth, colorA, colorB, repeatMode, time.
```

## Filet Grid Shader

```text
Create a shader that simulates filet crochet as an open/filled mesh grid. Each cell may be open lace or filled yarn bars based on a pattern mask. Use soft fiber edges, slight thread shadows, and chart-like cell structure.
```

## Ripple Chevron Shader

```text
Create a shader that renders crochet ripple chevrons using row-wise sinusoidal stitch placement. Use alternating yarn colors, loop glyphs, soft shadows, and visible peaks and valleys from increase/decrease logic.
```
