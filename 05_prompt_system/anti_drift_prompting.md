# Anti-Drift Prompting

Use this when image/code models start making generic yarn slop.

```text
This must read as crochet, not knitting, not weaving, not printed lace. Show hook-built loops, chain spaces, stitch posts, individual stitch bodies, top loops, motif joins, row or round structure, yarn twist, fiber fuzz, and small stitch-local shadows. Avoid generic cozy yarn texture, avoid V-shaped knit stitches, avoid woven warp/weft grids, avoid flat printed ornament.
```

## Common Repair Phrases

- make the stitch units more visible
- show chain spaces and crochet posts
- add crochet symbol-chart logic
- emphasize hook-built loops
- reduce generic fuzzy yarn mush
- preserve row/round/motif construction
